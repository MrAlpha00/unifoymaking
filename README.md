## 🚀 About The Project

**UniFoy Making** is a modern **service marketplace website** that connects users with professional service providers in:

- 🌐 Web Development  
- 📱 Mobile App Development  
- 🎨 UI/UX Design  

Built using **pure HTML, CSS, and JavaScript**, focusing on performance, simplicity, and modern UI.

---

## ✨ Features

- Glassmorphism UI design  
- Smooth hover animations  
- Responsive layout (mobile/tablet/desktop)  
- Dark theme with gradients  
- Login & Signup UI  
- Service pages with pricing  
- Policy pages (Terms, Privacy, Refund)  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla)  
- Google Fonts (Outfit)  
- Font Awesome
